# NASA Photo of the Day

This project is a simple one-page application that fetches the NASA Photo of the Day along with its title and caption. The application displays the photo as the background and aligns the title and caption at the bottom of the page.

## Project Structure

```
nasa-photo-of-the-day
├── src
│   ├── index.html        # Main HTML document
│   ├── styles.css       # CSS styles for the application
│   └── app.js           # JavaScript code to fetch data from NASA API
├── package.json          # npm configuration file
└── README.md             # Project documentation
```

## Getting Started

To run this project locally, follow these steps:

1. **Clone the repository:**
   ```
   git clone https://github.com/yourusername/nasa-photo-of-the-day.git
   cd nasa-photo-of-the-day
   ```

2. **Install dependencies:**
   ```
   npm install
   ```

3. **Open `src/index.html` in your browser:**
   You can simply open the HTML file in your web browser to view the application.

## Usage

The application will automatically fetch the NASA Photo of the Day when the page loads. The photo will be displayed as the background, with the title and caption shown at the bottom of the page.

## API Reference

This application uses the NASA API to fetch the Photo of the Day. You can find more information about the API [here](https://api.nasa.gov).
